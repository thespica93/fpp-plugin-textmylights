# Text My Lights - shipped EMOJI blacklist
#
# One entry per line:
#   a single emoji          -> blocked anywhere in the text   e.g.  🖕
#   emoji separated by space -> a COMBINATION: blocked only when ALL of them
#                              appear in the same text (any order, anywhere)
#                              e.g.  💦 👅
#   repeat an emoji to require it twice, e.g.  8️⃣ 8️⃣
#
# Skin tones and the emoji/text variation selector are ignored when matching,
# so 🖕 also blocks 🖕🏻 🖕🏽 🖕🏿 and ❄ matches ❄️.
# Lines starting with # are comments. Edit your own additions/removals from the
# plugin UI (Filters -> Manage Emoji Blacklist); this file is replaced on update.
#
# Sources: DEA "Emoji Drug Code | Decoded" chart; parent-safety emoji guides
# (Bark, Gabb, Net Nanny, Cyberwise); ADL Hate on Display / coded-hate research.
# Many of these emoji are innocent on their own - especially at Christmas
# (❄️ ⛄ 🌲 🍬 🍭 🍪 🎁) - so they are only blocked in COMBINATIONS.
